# Consumable flag — draft for Scott (2026-11-04)

The Part `consumable` flag is set on **0 of 1492** parts. This is the list to set it on.
**Nothing has been written.** Mark this file up, or just answer the four questions in Section 2,
and a script sets exactly what is agreed.

**Rule used for the draft:** *it is used up in use and you buy it again by quantity.* It does not
come back to a drawer the way a tool does. Category is NOT the test: `Consumables/Solder` also holds
soldering stations, mats, a magnifier lamp and a toggle switch (Section 3).

Source: `scripts/consumable_survey_1104.py` (read-only): the three consumables category trees,
plus a keyword sweep of every active part. **Not every part was read by eye.** A consumable named
oddly in a non-consumable category (for example a rag, a glove, or an unnamed tube of grease) can be
missing. Section 4 says what was not looked at.

## 4. Not covered by this draft

- **Cutting tools** (end mills, drills, taps, inserts, about 100 parts under `Tooling/`). They wear out,
  but here **a cutter is a tool**: each one carries a T number through `tool_tag.py`. Draft says no.
- **Fasteners and hardware** (`Hardware`, `Mechanical`): see question B.
- **Electronic components** (resistors, capacitors, ICs): these are components that go into builds. Out of scope.
- **Items with no record:** the Rigidax machinable wax is a known consumable with no InvenTree part at all (top-level CLAUDE.md).
- Qty 0 is not a reason to skip a part. The flag belongs to the part, not to the stock on hand.
