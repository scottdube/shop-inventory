## 2. Duplicates, and what is not one

**Zero genuine cross-tree duplicates.** A normalised-name containment check
across all 41 live parts in the two categories returned no pairs. The two trees
hold different *kinds* of record, not different copies of the same record:
`[2]` holds nine purchase-seeded kit/pack rows, `[69]` holds decomposed values
with counted stock plus four individually-bought resistors.

### Not duplicates — receipts, already settled

| Part | Why it is 0 and inactive |
|---|---|
| [#448 ALLECIN 25-value kit](http://inventory.internal/web/part/448) | Deactivated as duplicate of #1; notes say so |
| [#143 uxcell 220R 1206](http://inventory.internal/web/part/143) | REFUNDED, sole item on the order — never inventory |
| [#502 100pcs 1/2W 1R-2M](http://inventory.internal/web/part/502) | Retired: "an assortment kit is a LOCATION, not a part" |

### Not a duplicate — decomposition, and correct at 0

[#211 EAONE 30 Values 1% Resistor Kit](http://inventory.internal/web/part/211)
is **on hand and correctly counted.** Its contents are the thirty
`Resistor … 1% 1/4W` parts in `[69]`, all sited in
`SLN/Laser Area/L2/L2-D4/Kits/Kit - EAONE Resistor 30-value`, **839 pieces
counted** across 30 stock rows (28 each, less the one 1 k drawn to
`RB-25`).

So the kit's 0 is the assortment-kit-is-a-LOCATION convention working. Writing
a count onto #211 would **double-count 839 resistors**. The only residual
defect is cosmetic: #211 is still `active=True`, where the identically-shaped
#502 was retired with a pointer in its description.

## 4. Safety checks run before proposing any move

- MPTT health on `PartCategory`: no tree_id with more than one root, zero stale
  pathstrings. The tree is sound, so a re-parent will behave.
- Nothing in this repo — scripts, BinScan, plugins, label templates — refers to
  `Passives/Resistors` by path. No code breaks when it goes.
- No BOM anywhere uses any of the nine legacy parts (`get_used_in()` = 0 for
  all), and none is a variant parent.
- `[2]` holds **0 stock rows**. `[69]` holds 34 rows, 924 pieces. A move
  relocates no physical stock.
